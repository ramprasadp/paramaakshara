# Script conversion

How Paramaakshara writes Sanskrit in Kannada and Tamil (TECH_SPEC §7).
Code: `frontend/src/conversion/script.ts`; tables generated by
`tools/gen-script-tables.py` from the Unicode Character Database.

## Pipeline

-   ITRANS is converted to Devanagari (`docs/itrans-mappings.md`), then
    to the output script.
-   Text already in Kannada or Tamil is first read back to Devanagari,
    so a line may mix scripts and still convert.
-   Vedic accents (U+0951, U+0952, U+1CDA, U+0953), dandas (। ॥) and
    other shared characters are kept as they are in every script.
-   The Taittirīya anusvara signs ꣳ ꣴ (U+A8F3/U+A8F4) have no Kannada or
    Tamil form; they are kept and reported.
-   A character that cannot be represented is **kept and reported**,
    never dropped. A character written approximately is reported as
    "not reversible".

## Kannada

One-to-one with Devanagari for everything in Sanskrit text, by the
shared ISCII layout (each pair checked by Unicode name):

  Devanagari           Kannada            Notes
  -------------------- ------------------ ------------------------------
  अ … औ, क … ह, ळ       ಅ … ಔ, ಕ … ಹ, ಳ     Devanagari `E`/`O` (ए ओ) are
                                          the long vowels ಏ ಓ; `e`/`o`
                                          (ऎ ॆ ऒ ॊ) are the short ಎ ೆ ಒ ೊ
                                          (`docs/itrans-mappings.md`)
  ं ः ँ ऽ ्             ಂ ಃ ಁ ಽ ್
  ० … ९                ೦ … ೯
  ॐ                    ಓಂ                 No Kannada OM sign; reported,
                                          not reversible

Devanagari → Kannada → Devanagari is exact on both sample texts.

## Tamil (superscript convention)

  Devanagari                Tamil
  ------------------------- --------------------------------------------
  क ख ग घ ङ                  க க² க³ க⁴ ங
  च छ ज झ ञ                  ச ச² ஜ ஜ² ஞ
  ट ठ ड ढ ण                  ட ட² ட³ ட⁴ ண
  त थ द ध न                  த த² த³ த⁴ ந
  प फ ब भ म                  ப ப² ப³ ப⁴ ம
  य र ल व                    ய ர ல வ
  श ष स ह ळ                  ஶ ஷ ஸ ஹ ள
  ं ः ॐ                      ம் ஃ ௐ
  ० … ९                      ௦ … ௯

-   **Superscript position:** after the syllable's vowel sign or virama
    and accents, before an anusvara or visarga: भू॑ → பூ॑⁴, द्ग → த்³க³,
    भं → ப⁴ம், भः → ப⁴ஃ. Accents stay on the Tamil letter, and the
    superscript never carries a combining mark.
-   **Reading back:** a superscript modifies the nearest preceding
    consonant of its syllable, so Tamil with superscripts converts back
    exactly.
-   **Approximate (reported, not reversible):** ऋ ॠ ऌ ॡ → ரு ரூ லு லூ;
    ृ ॄ ॢ ॣ → ்ரு ்ரூ ்லு ்லூ.
-   **Kept in Devanagari (reported):** chandrabindu ँ and avagraha ऽ, which
    Tamil cannot write.
-   **Anusvara:** written ம், as in printed Tamil Sanskrit texts (decided
    by the project owner, 2026-11-09). It reads back as म्, so ं does not
    survive a round trip; this is part of the convention and is not
    reported on every line. The Tamil sign ஂ U+0B82 would be exact but
    looks much like the puḷḷi (்) in the bundled font.

Devanagari → Tamil → Devanagari is exact on both sample texts, apart
from anusvara (ं → म्) and lines with ऋ/ृ, which are reported.

## Fonts

Noto Serif Kannada and Noto Serif Tamil (OFL-1.1) are bundled; both
contain the Vedic accents. The output pane uses one font stack, so mixed
lines render each script in its own font.
